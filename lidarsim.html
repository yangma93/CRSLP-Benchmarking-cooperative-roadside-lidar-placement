LidarSIM：
以真实环境点云为背景的车路协同感知仿真

LidarSIM 以真实道路环境点云为背景，基于 GPU 并行 ray-casting 仿真多路路侧与车载 LiDAR， 内置物理强度、扫描时序运动伪影、雨雪杂波与多雷达布设对比，并将感知结果回写 SUMO 形成闭环， 为车路协同感知研究提供可复现的仿真与评价平台。

Perception Simulation

车路协同 · 多类天气 · Ego 视角

同一套仿真内核输出路侧、车端与多视角点云，光束模式、逐束时刻与噪声模型保持一致。

车路协同感知

路侧与车端点云按目标融合，遮挡区域互补，同一目标获得更完整的观测。

多类天气仿真

雨、雪粒子谱驱动消光、后向散射与虚假回波，支持感知鲁棒性测试。

Ego 视角仿真

车载 LiDAR 逐帧位姿与逐束扫描时刻，复现真实运动伪影与自车遮挡。

布设条件变化下的感知性能

雷达高度、角度与数量的变化，实时反映在覆盖范围与协同 IoU 上。

Engine Acceleration

底层算法提升：v1 → v4

在不改变任何一帧点云的前提下，重构环境求交与车辆求交的关键路径。

  • 块级采样上限收缩、int32 扁平体素索引与单字节占用表
  • GPU atomicMin 打包归约，替代候选点全量排序
  • 逐车 slab 粗筛、单次打包 D2H、法向与扫描模式缓存
  • 多 CAV 光线合批，减少小 kernel 提交
1.40× 单帧平均加速比
0 逐元素点云最大差异

SUMO Co-simulation

与 SUMO 联合仿真，并把感知结果回写

每一步 SUMO 交通状态驱动在线轨迹，LidarSIM 生成路侧与车端点云并完成 L-shape 协同感知评估； IoU 与感知状态写回 SUMO 车辆颜色与自定义参数，可选 TTC 闭环减速。

  • 逐帧锁步：绘制完成才推进下一步
  • 绿 / 红反馈：IoU 达到阈值即视为协同感知成功
  • 支持无背景点云：由 net.xml 生成路面点阵

底图绘制

SUMO netedit 风格的点云底图编辑器，导出 net.xml 与可直接运行的场景。
